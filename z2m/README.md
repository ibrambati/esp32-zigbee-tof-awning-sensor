# Zigbee2MQTT files

Everything needed on the Zigbee2MQTT side for the [Arduino firmware](../arduino/README.md).

```
z2m/
├── README.md
├── awning_tof.mjs     # external converter (entities + OTA support)
└── ota/
    ├── make_ota.py    # builds the .zigbee image and updates index.json
    ├── index.json     # OTA index read by Zigbee2MQTT
    └── *.zigbee       # OTA images, one per release
```

## Converter (`awning_tof.mjs`)

Maps the custom cluster `0xFC00` of the firmware to Zigbee2MQTT entities and declares OTA support (`ota: true`). Attribute IDs and types must stay identical in the sketch and in the converter: change both together.

1. Copy the file to `<Zigbee2MQTT data folder>/external_converters/awning_tof.mjs` (next to `configuration.yaml`).
2. With Zigbee2MQTT 2.11 or newer, new installations have external converters disabled: set `enable_external_js: true` in the `advanced` section.
3. Restart Zigbee2MQTT, remove the old device if it was already paired and pair it again (needed whenever clusters or attributes change).

Entities: opening percentage, distance (cm), battery percentage and voltage, status, link quality, and the writable parameters (zero, max length, laser on/off, deep sleep on/off, start and end hour, read interval, LED mode).

## OTA (`ota/`)

The images and the index are generated by `make_ota.py` and served from this repository. The full procedure (version, compile, build the image, commit, install) and the list of what is committed and what is not are in [`docs/OTA.md`](../docs/OTA.md).

Zigbee2MQTT side in short, in `configuration.yaml`:

```yaml
ota:
  zigbee_ota_override_index_location: https://raw.githubusercontent.com/ibrambati/esp32-zigbee-tof-awning-sensor/main/z2m/ota/index.json
```
